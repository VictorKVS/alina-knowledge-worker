# Cultural Prediction Lab

Здесь хранятся исторические, фольклорные и дивинационные системы предсказаний.

Примеры:

- астрология;
- хиромантия;
- нумерология;
- гадательные таблицы;
- иные исторические системы правил.

## Почему они допускаются в Future Lab

Цель — не подтверждать их истинность, а:

1. формализовать правила;
2. показать происхождение правил;
3. воспроизводимо реализовать расчёт;
4. провести blind/backtest;
5. сравнить с baseline и научными моделями;
6. сохранить фактический результат.

## Жёсткая маркировка

Каждый такой метод получает:

```text
evidence_class = NON_SCIENTIFIC
```

Он не может:

- повышать научный confidence;
- смешиваться с SCIENTIFIC_A/B без явного разделения;
- называться доказанным только потому, что дал отдельные совпадения.

## Научная оценка

Для астрологии в реестре используется, среди прочего, опубликованный в Nature двойной слепой тест как источник именно для **оценки заявленной predictive validity**, а не как источник астрологических правил.

Для хиромантии отдельно потребуются:
- исторический источник самих правил;
- научные исследования валидности, если существуют;
- независимый backtesting на заранее зафиксированных исходах.
