# FATHER Professional Reference Registry

## Purpose
Canonical registry of professions, specializations, competencies, knowledge requirements, skills, tools, methods, quality expectations and qualification rules used by AK-01.

The registry is not a static list of job titles. It is a structured professional reference graph.

## Core formula

PROFESSION
+ SPECIALIZATION
+ RESPONSIBILITY LEVEL
+ PRODUCT REQUIREMENTS
+ QUALITY CLASS
+ ORGANIZATION CONTEXT
= TARGET SPECIALIST PROFILE

## Registry layers

1. profession families
2. roles and specializations
3. competency models
4. knowledge areas
5. skills
6. methods and procedures
7. tools and technologies
8. quality requirements
9. security requirements
10. qualification evidence

## Rule
AK-01 must never equate a job title with competence.
A title is only a label; qualification is demonstrated by the competency vector and evidence.
