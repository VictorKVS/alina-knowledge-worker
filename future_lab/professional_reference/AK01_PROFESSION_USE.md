# AK-01 Use of Professional Registry

AK-01 workflow:

PROJECT PACKAGE
→ identify product tasks
→ identify required decisions
→ match profession families
→ select/create specialization
→ build competency vector
→ derive knowledge requirements
→ compare with FATHER knowledge
→ identify gaps
→ acquire missing sources
→ build Knowledge Packets
→ create training handoff
→ qualification

## Important
Professional Reference Registry is a starting prior, not absolute truth.

Project-specific requirements may:
- increase required depth;
- add new competencies;
- remove irrelevant areas;
- combine multiple professions;
- require a multi-agent team.

## Unknown profession
If no matching profession exists:
1. build task graph from product;
2. derive decisions;
3. cluster competencies;
4. compare against adjacent professions;
5. synthesize provisional profession profile;
6. qualify through evidence and tests;
7. propose new profession reference to the registry.
