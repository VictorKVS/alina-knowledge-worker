# Training Handoff Contract

AK-01 does NOT own curriculum generation.

AK-01 produces prerequisites and competency structure.
A downstream training architect agent consumes this output.

Input to Training Architect:
- target agent role
- capability map
- knowledge graph
- prerequisite edges
- competency weights
- weak areas
- evaluation requirements
- qualified sources

Training Architect output:
- learning objectives
- sequence
- modules
- exercises
- labs
- assessments
- mastery thresholds
- remediation paths
- final qualification exam

This separation prevents knowledge extraction from being biased toward a premature course structure.
