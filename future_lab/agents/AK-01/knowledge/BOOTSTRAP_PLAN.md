# AK-01 — Knowledge Bootstrap Plan

## Phase K0 — Operating Core

Load only the minimum knowledge required for AK-01 to work:

- knowledge engineering fundamentals
- RAG fundamentals
- graph/provenance model
- source/evidence model
- prompt/context architecture
- procedures/checklists
- agent role/task/capability decomposition
- test/evaluation rules
- security invariants

Exit:
AK-01 can create a schema-valid Knowledge Blueprint from a small curated source set.

## Phase K1 — Retrieval Competence

Add:
- hybrid retrieval
- reranking
- graph retrieval
- metadata filtering
- freshness
- citation grounding
- retrieval evaluation

Exit:
AK-01 can design target-agent RAG and pass retrieval tests.

## Phase K2 — Knowledge Architecture Competence

Add:
- ontology/taxonomy
- entity normalization
- contradiction management
- prerequisite graphs
- impact analysis
- contextual weighting

Exit:
AK-01 can create a versioned weighted knowledge graph.

## Phase K3 — Operational Knowledge Competence

Add:
- procedure synthesis
- decision rules
- checklists
- stop/escalation conditions

Exit:
AK-01 can transform declarative knowledge into operational knowledge.

## Phase K4 — Specialist Factory Competence

Add:
- specialist capsule
- training handoff
- local knowledge layers
- knowledge delta
- requalification lifecycle

Exit:
AK-01 can build and maintain knowledge capsules for another agent.

## First qualification target

FATHER Forecasting Agent.

AK-01 must produce:
- target-agent profile
- capability map
- knowledge graph
- RAG spec
- prompt package
- procedures
- checklists
- gaps
- evidence chain
- training handoff
