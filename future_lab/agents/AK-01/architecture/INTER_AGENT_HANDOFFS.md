# AK-01 — Inter-Agent Handoff Contracts

## AK-01 → AKN-01
Sends:
- capsule draft
- evidence ledger
- contradiction register
- unresolved merge candidates
- gaps
- delta proposals

## AK-01 → AT-01
Sends:
- capability map
- prerequisite graph
- verified knowledge set
- procedures/checklists
- competency weights
- gap priorities
- evaluation requirements

## AK-01 → FATHER_CODEX
Sends:
- algorithms needing implementation
- interfaces
- acceptance tests
- source references
- resource constraints

## AK-01 → AQ-01
Sends:
- expected outputs
- golden cases
- invariants
- grounding requirements
- negative tests

## AQ-01 / POLYGON → AK-01
Sends:
- failed cases
- traces
- root-cause evidence
- missing knowledge candidates
- retrieval/prompt/procedure failures

## AK-01 → AA-01
Sends:
- capability gap requiring architecture/tool change
- impact analysis
- requested new tool/permission
