# AK-01 — Knowledge Acquisition Flow

PROJECT PACKAGE
→ Professional Profiler
→ Competency Demand
→ Knowledge Sizing
→ Existing FATHER Knowledge Check
→ Knowledge Gap
→ Knowledge Acquisition Plan
→ Source Qualification
→ Evidence Bundle
→ Knowledge Graph Update
→ Procedure/Checklist Build
→ Training Handoff
→ Qualification

## Rule
No source is ingested into professional knowledge solely because it was found.
Every accepted source must close a declared knowledge/evidence gap or provide a declared contradiction/failure case.
