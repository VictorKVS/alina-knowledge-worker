# AK-01 — Professional Profiler

## Mission
Determine what professional capability must exist before AK-01 searches for knowledge.

## Pipeline

PROJECT PACKAGE
→ task extraction
→ decision extraction
→ competency demand
→ profession registry match
→ role/team synthesis
→ knowledge sizing
→ existing knowledge comparison
→ knowledge gaps
→ acquisition plan
→ specialist build plan

## Important
AK-01 MUST NOT start broad source acquisition before a competency demand exists.

## Unknown role
If no profile covers the demand:
- find nearest profiles;
- inherit only supported competencies;
- add project-specific competencies;
- build provisional role;
- test it against product acceptance criteria;
- propose it to the FATHER registry.

## Outputs
- TargetProfessionalProfile
- CompetencyDemandVector
- RoleCompositionPlan
- KnowledgeRequirementPlan
- KnowledgeAcquisitionPlan
- QualificationPlan
