# AK-01 — Knowledge Acquisition Engine

## Mission
Convert a verified knowledge gap into a reproducible source acquisition plan.

The engine does not "search the web for information".
It plans evidence acquisition against a specific professional knowledge requirement.

## Input
- target_professional_profile
- competency_id
- knowledge_gap_id
- required_depth K0-K5
- criticality
- related_tasks
- related_decisions
- quality_class
- domain_source_policy

## Pipeline

KNOWLEDGE GAP
→ DEFINE CLAIM/QUESTION SET
→ CLASSIFY KNOWLEDGE TYPE
→ DEFINE REQUIRED EVIDENCE TYPES
→ DEFINE SOURCE MIX
→ SEARCH STRATEGY
→ CANDIDATE COLLECTION
→ SOURCE QUALIFICATION
→ CLAIM-EVIDENCE MAPPING
→ COVERAGE CHECK
→ CONTRADICTION CHECK
→ PRACTICE/FAILURE CASE ACQUISITION
→ SUFFICIENCY CHECK
→ STOP / EXPAND SEARCH

## Knowledge types
- foundational
- conceptual
- procedural
- algorithmic
- normative
- implementation
- operational
- security
- quality
- failure/anti-pattern
- frontier/research

## Core principle
Search is gap-driven and claim-driven, not topic-driven.
