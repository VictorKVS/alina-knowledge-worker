# AK-01 — Evidence Search Strategy

## Search order

1. Existing FATHER qualified knowledge
2. Primary normative / official sources
3. Bodies of knowledge / professional frameworks
4. Scholarly synthesis / systematic review
5. Primary research
6. Canonical books / monographs
7. Official technical documentation
8. Reproducible engineering case studies
9. Discovery sources

## Query generation
For each gap generate queries for:
- definition
- mechanism
- decision criteria
- prerequisites
- limitations
- failure modes
- alternatives
- implementation
- testing
- security
- operations

## Example

Gap:
Database transaction isolation, K4

Queries must cover:
- isolation level semantics
- anomalies
- MVCC
- locking
- deadlocks
- choice criteria
- PostgreSQL implementation specifics
- failure/testing scenarios

## Stop rule
Do not continue broad searching after evidence coverage and qualification thresholds are satisfied.
