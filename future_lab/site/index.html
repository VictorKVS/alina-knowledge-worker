«Расчёты будущего»

Лаборатория воспроизводимых прогнозов. Каждый результат должен показывать: какой метод применён, на каких данных, по какому алгоритму, из какого авторитетного источника и как метод прошёл backtesting.

TASK → CLASSIFY → SELECT METHODS → CHECK ASSUMPTIONS → RUN → COMPARE / ENSEMBLE → FORECAST → KNOWN FUTURE → BACKTEST → METHOD SCORE REGISTRY

Объединение прогнозов / Ensemble Lab

Несколько независимых методов дают свои прогнозы, после чего отдельная стратегия рассчитывает веса и формирует комбинированный прогноз. Веса затем проверяются и обновляются по фактическим ошибкам.

METHOD A + METHOD B + METHOD C → WEIGHT STRATEGY → ENSEMBLE → FACT → BACKTEST → UPDATE WEIGHTS
