# AK01-SELF-01 — End-to-End Factory Line

## Purpose

Prove the FATHER principle:

> A component is not ready until its behavior is proven as part of the final production line.

This experiment exercises the first complete AK-01 knowledge/problem-solving line without live external dependencies.

## Production line

WORK OBJECT
→ WORK DECOMPOSITION
→ GAP/FINDING
→ RESEARCH PLAN
→ SOURCE DISCOVERY PLAN
→ SOURCE QUALIFICATION
→ CLAIM/EVIDENCE LINK
→ KNOWLEDGE UNIT
→ EXTERNAL QUALIFICATION
→ PROFESSIONAL KNOWLEDGE GRAPH
→ RUNTIME ACCESS
→ PROBLEM SIGNATURE
→ METHOD CANDIDATE
→ COMPARISON/SELECTION
→ OUTCOME
→ ROOT CAUSE
→ LEARNING ROUTE

## Invariants

1. Missing knowledge is reported, not invented.
2. Discovery never means acceptance.
3. Source acceptance is claim-scoped.
4. Evidence retains exact fragment provenance.
5. Counter-evidence remains visible.
6. AK-01 cannot self-qualify.
7. Unqualified knowledge cannot enter runtime.
8. Method selection requires evidence, metrics, failure modes, and explicit criteria.
9. Timing claims require measurement evidence.
10. Production outcomes are append-only evidence.
11. Root-cause evidence determines the correction route.
12. A correction must later become a regression test.

## Initial scenario

The initial E2E case is intentionally small:

"Choose a retrieval strategy under a latency constraint."

It proves the machinery, not retrieval expertise. Live scientific/source connectors are introduced only after the deterministic line is stable.
