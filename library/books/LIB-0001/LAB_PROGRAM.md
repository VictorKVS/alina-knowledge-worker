**Статус лабораторной программы:** SECONDARY_SOURCE_PARTIAL

**Канонический учебный проект:** [открыть](../BOOK-001_AI_Engineering/README.md). Программа ниже — обзор; отдельные лаборатории по известным главам/руководствам находятся в каноническом проекте.

## Предварительная цель

**Исследовательское направление:** AI application evaluation.

**Объект испытания:** Сравнить простой prompt, RAG и ограниченного агента на одном корпусе. Применимость к ALINA / FATHER Architect.

## Лаборатория A — учебная

Изолированные тестовые данные; разобрать конкретный алгоритм после чтения исходной главы, вручную вычислить контрольный пример, реализовать минимальную проверку, зафиксировать вход → ожидаемый результат и не менее трёх крайних случаев. Сравнить с простым baseline. `NOT_RUN`.

## Лаборатория B — сравнительная

Сопоставить минимум две разрешённые реализации/вариации без изменения контрольного набора; измерять: accuracy, recall@k, groundedness, latency, cost. Повторить эксперимент, записать версии, seed, ресурсы и стоимость. Проверить негативный сценарий: **prompt injection и отсутствие источника**. `NOT_RUN`.

## Лаборатория C — интеграционная

Определить контракт `ALINA Knowledge/Prompt/RAG/Algorithm Package → FATHER Agent Factory → UAG → POLYGON`. Подключать лишь допущенные инструменты; сверить права, provenance, логи, fail-closed, откат и влияние на соседние компоненты. `NOT_RUN`.

## Программа каждой фактической главы

**После получения/прочтения первоисточника** создать отдельный `CHxx/LAB_PROGRAM.md` с точной темой, страницами, гипотезой автора, вариантом A/B/C, программой запуска, test fixtures, expected results, метриками, безопасностью, acceptance gate. Если глава не содержит самостоятельного алгоритма, проверять описываемый метод через сравнение/наблюдение и явно фиксировать этот выбор.

## Предварительные пороги приёмки

Критические нарушения доступа/утечки = 0; структурная валидность результатов = 100% (целевой порог до эксперимента); качество/скорость/стоимость определяются по baseline и ограничениям задачи. **Это целевые критерии, не измеренные результаты.** Отрицательные и пограничные проверки обязательны.

## Evidence

Нужны source hashes, версия кода/модели, тестовые данные, raw logs, метрики, ADR и независимый POLYGON. Пока нет запуска: `DESIGNED_ONLY / NOT_TESTED / NOT_QUALIFIED`.
