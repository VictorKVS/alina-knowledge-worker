# ADR-DUAL-0001 — две специализации, один контракт агентного решения

**Дата:** 2026-11-24. **Решение:** принять два симулятора — история и игра — при общем lifecycle `observe → available actions → choose → validate → step → observe`.

**Мотивация:** изучать те же паттерны CH02 Routing, CH03 Parallelization, CH04 Reflection, CH05 Tool Use, CH08 Memory и видеть почему стратегия, данные, инструменты и валидация различаются.

**Альтернативы:** (a) два независимых крупных продукта — нет, дублируют core; (b) сразу game engine/Unity — нет, слишком много несвязанных зависимостей; (c) один симулятор с переименованием сущностей — нет, не выявляет доменные различия.

**Инварианты:** rules of world are deterministic and enforced in code; LLM proposal is not permission; all actions must be allowed by current state; budgets cannot be negative; explicit success criteria; store observable traces; no claim of real learning with only a loop.

**Ограничения:** маленькие среды, ручные веса score и toy episode; не игра с настоящей графикой; не полнофункциональный сюжетный LLM генератор; требования вакансии не подтверждены. Заказные интеграции — следующая фаза.

**Security:** input size/step limits, no external tool execution, no arbitrary Python or shell generated by LLM, no secrets in traces; role UAG added before connecting real capabilities.

**Acceptance:** user-run tests on Windows/Python 3.10; additional LLM tool support benchmark and independent POLYGON tests before product claims.
