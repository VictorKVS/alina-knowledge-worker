# Практикум FATHER — топология агентов с RabbitMQ (проект на 2026 год)

## Цель

Проверить на реальной, локально запускаемой инфраструктуре, что сообщения между агентными ролями доставляются, сохраняют уникальную идентичность, не теряются без регистрации при сбое и не дают вторичных действий при повторной доставке.

## Этап A — без брокера

Реализовать учебную последовательность ALINA → Architect → UAG → Worker → POLYGON как обычные функции Python. Добавить JSON Schema для `task_id`, `requester`, `payload_ref`, `action_id`, `status`.

## Этап B — нужен ли RabbitMQ?

Сравнить прямые вызовы и message broker по критериям: связь компонентов, восстановление после сбоев, независимость рабочих процессов, журналирование, цена эксплуатации. Если брокер не даёт измеримого преимущества, он не нужен.

## Этап C — минимальная очередь

На стенде Docker (после проверки образа и лицензии) поднять RabbitMQ, создать `tasks.exchange`, `agent.alina.tasks` и `agent.architect.tasks`, с раздельными учётными записями. Отправить тестовое сообщение с correlation_id, дождаться ACK.

## Этап D — отказ и доставка повторно

Имитировать выключение worker до ACK. Убедиться, что сообщение не исчезает без следа. Добавить idempotency по `action_id` и проверить, что повторно доставленное сообщение не повторяет операцию.

## Этап E — DLQ и безопасность

Отправить заведомо некорректное сообщение, направить в карантин, настроить таймаут, пороги и аудит. Запретить агенту-исполнителю доступ к очередям другого контура. Сохранять в очередях только минимально необходимые данные.

## Этап F — qualification

POLYGON должен проверить:
1. Сохранение корреляции между запросом и ответом.
2. Повторную доставку после сбоя.
3. Однократность побочного эффекта через idempotency.
4. Отсутствие несанкционированного доступа.
5. Реальные метрики задержки и throughput.
6. Возможность восстановления из DLQ / quarantine по разрешённому регламенту.

## Контрольная шкала

- `DESIGNED` — только текстовые схемы.
- `IMPLEMENTED` — код и конфигурация написаны.
- `TESTED` — есть измерения и логи.
- `QUALIFIED` — независимый POLYGON подтвердил контракт.

**Текущее состояние:** DESIGNED, стенд RabbitMQ не запускался этой задачей.
