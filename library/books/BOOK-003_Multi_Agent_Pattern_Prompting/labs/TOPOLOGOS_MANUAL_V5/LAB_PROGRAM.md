# BOOK-003 — лаборатория Topologos Manual v5

**Источник:** официальное руководство Topologos Manual v5 из репозитория издателя, не вся книга. **SOURCE_REVIEWED_MANUAL_ONLY / NOT_RUN**.

## A — учебная
Задать 3 схемы обмена сообщениями: direct, work queue, publish/subscribe; вручную проверить маршруты сообщений и допустимые направления. Выделить ingress, очереди, агентов, владельцев данных.

## B — сравнительная
Сравнить конфигурацию RabbitMQ с фиксированным безопасным шаблоном на синтетических событиях; измерить доставку, повторы, ordering, retries, dead-letter и восстановление. Топология, предложенная LLM, не принимается без верификации.

## C — интеграционная
`ALINA generates topology specification → FATHER validates contracts → UAG authorizes tool routing → isolated RabbitMQ → POLYGON injects failures → evidence`.

Сценарии: дублирование, потеря связи, заражённое текстовое сообщение (не исполнять инструкцию), нескончаемая пересылка, переполненная очередь, отсутствие авторизации.

**Критерии:** нет пересечений зон доверия, нет незарегистрированных потерянных сообщений, исчерпаны retry budgets, dead-letter/fail closed работает. Цифровые значения согласовываются до прогона. Статус NOT_RUN.
