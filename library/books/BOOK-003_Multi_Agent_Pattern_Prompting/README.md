## Назначение

Topologos — системный промпт, который помогает LLM **проектировать** RabbitMQ-топологии под агентные паттерны. Он не является брокером сообщений, не развертывает инфраструктуру автоматически и не доказывает её корректность одним текстовым ответом.

Границы: в конкретном руководстве используется RabbitMQ; автоматически переносить конфигурации на Kafka, NATS или SQS нельзя. Генерация IaC требует проверки актуальности версий, безопасности и испытаний.
