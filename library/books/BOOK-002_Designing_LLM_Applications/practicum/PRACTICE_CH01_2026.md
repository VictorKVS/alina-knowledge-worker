# Практикум BOOK-002 / CH01 — «Поговори с документом»

**Первый курс МАИ.** Сначала понимаем, что делает каждая программа; затем заменяем примитивные узлы современными. Этот пример не требует отправлять пользовательский PDF в сторонние сервисы.

## Лабораторная работа 1 — найти информацию без LLM

- Используйте [уже опубликованный учебный Python-поиск](../../../labs/2026_document_search/README.md).
- Напишите три собственных технических абзаца и присвойте им имена SOURCE-01/02/03.
- Подготовьте 5 вопросов, для каждого — ожидаемый источник.
- Запустите tests, дополните отрицательным вопросом.
- Зафиксируйте качество: `Recall@1 = correct_source_first / total_questions`.
- Зафиксируйте ограничения: лексическая система плохо обрабатывает синонимы.

## Лабораторная работа 2 — получить embeddings

Это следующий, **не выполненный автоматически**, этап. Используйте локально доступную embedding-модель, сравните семантический поиск с исходным baseline на том же наборе вопросов; проверьте размерность векторов и версию модели.

## Лабораторная работа 3 — подключить LLM

Подключить локальный inference runtime или внешний API **после допуска информации к обработке**. Формировать ответ только по найденным источникам; хранить точные source_id и отказаться от неподтверждённых утверждений.

## Лабораторная работа 4 — эксплуатация

Измерить latency, качество цитат, права доступа к документам. Задать роли (например, инженер и стажёр) и протестировать, что стажёр не получает документы инженера.

## Пример исходной архитектуры

```text
USER
  -> authentication
  -> document permission filter
  -> retrieval (source_id, page, version)
  -> optional LLM inference
  -> verification / citation policy
  -> output + redacted audit trace
```

**Обратите внимание:** в исходном PDF стр. 78–85 прототип использует Python, LangChain, embeddings и Chroma. Перечисленный выше путь — наша учебная адаптация к требованиям эксплуатации и безопасности; мы не заявляем, что приведённый в книге API-код остаётся совместимым с библиотеками 2026 года.

**Эталон результата:** воспроизводимый запуск, 5 вопросов, таблица найденных документов, негативный случай, версионированный исходный корпус и протокол ошибок.

**Статус:** инструкции подготовлены, фактические внешние испытания не выполнены.
