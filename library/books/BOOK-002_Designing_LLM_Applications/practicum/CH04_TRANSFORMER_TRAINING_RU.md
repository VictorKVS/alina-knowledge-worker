## Лаборатория B — обучение vs использование

Нарисуй для агента две схемы:
- **Inference:** tokenizer → model forward → logits → decoder → output. Model weights frozen.
- **Training:** tokenizer → input/target pairs → forward → loss → backprop → optimizer step → versioned checkpoint → independent evaluation.

Покажи, в какой момент RAG изменяет **входной контекст**, но **не изменяет параметры** модели.

## Лаборатория C — выбор архитектуры

- Извлечение вектора для семантического поиска → попробовать embedding/encoder-type модель.
- Генерация ответа и кода → проверить decoder-only.
- Перевод/преобразование последовательности → сравнить encoder-decoder с генеративной моделью.
- Сравнить итог не только по архитектуре, но по качеству на задачах, правам, latency, VRAM и стоимости.

## Лаборатория D — PGN против свободного текста

1. Подготовить малый **синтетический** набор событий обработок документов, где известны верные действия.
2. Описать каждый случай как свободный текст и как стандартизированное JSON-событие.
3. Зафиксировать **одинаковый** набор задач и метрики: correct decision, false merge, citation and token cost.
4. На одной и той же LLM провести сравнение, не меняя остальные условия.
5. Зафиксировать случаи, где структурированные данные помогают или мешают.

Шахматный эксперимент книги не запускается повторно и не объявляется результатом FATHER. Это гипотеза для отдельного сравнения.
