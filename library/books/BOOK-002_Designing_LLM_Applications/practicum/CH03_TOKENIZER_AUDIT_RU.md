# BOOK-002 / CH03 — Лабораторная работа по токенизации

## Часть A — BPE своими руками

[Учебный алгоритм BPE](../alina_kb/labs/ch03_bpe.py) реализует частотное слияние символов по примеру `bat, cat, cap, sap, map, fan` из книги (PDF 191–192). Он демонстрационный, а не совместимый с tokenizer Llama или GPT.

Запуск из каталога `alina_kb/labs`:

```powershell
python -m unittest -v test_ch03_bpe.py
python ch03_bpe.py
```

Проверь, что самая частая пара — `('a','p')` и что после первого слияния она превращается в один символ `ap` внутри `cap/sap/map`.

## Часть B — измерения на реальной модели

Нужна установленная совместимая библиотека и фактический tokenizer файл выбранной модели. Нельзя подменять реальные значения придуманными.

1. Зафиксировать модель, ревизию и sha256 файла tokenizer (если доступен).
2. Подготовить одинаковый по содержанию текст на русском и английском (мин. 20 пар).
3. Добавить отдельные технические фрагменты: ИБ, OSINT, Kubernetes, JSON, URL, даты.
4. Посчитать token IDs, количество токенов, слов, fertility и parity на точном tokenizer.
5. Выявить случаи, где техническая единица дробится на много токенов.
6. Сравнить контекстный budget и влияние на RAG chunking.
7. Сохранить результаты по каждому примеру, необычные разбиения и ошибки.
8. Проверить то же для **embedding-модели**, если у неё отдельный tokenizer.

**Gate:** без реально загруженного tokenizer и воспроизводимых результатов измерения не считать завершёнными.

## Часть C — ALINA Agent Factory

ALINA создаёт `TokenizerCompatibilityReport` для каждого агента. Он включает язык/домен, target model/tokenizer version, fertility, parity, special tokens, max input/output budget, known anomalies, proposed chunking and prompt-budget rules.

POLYGON проверяет случаи: многословные имена, смешанный Unicode, длинные номера приказов, таблицы, ошибочные символы и недопустимую потерю цитат.

## Критическая граница

Токенизация не проверяет достоверность или права на материал. Качество исходных данных и безопасность контролируются предыдущими этапами ALINA.
