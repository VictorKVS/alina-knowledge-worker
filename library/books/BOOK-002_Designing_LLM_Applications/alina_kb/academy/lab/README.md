# Учебная лаборатория

В каталоге `lab`: `python -m unittest -v`, затем `python decision.py`. Только искусственные метаданные и стандартная библиотека Python. Не делает реальных поисков дубликатов, юридических проверок или обнаружения ПДн.

Результат — **учебная классификация**, а не система, которую можно допускать в промышленное применение. Нужны настоящие поля provenance, policy engine, human review и POLYGON.
