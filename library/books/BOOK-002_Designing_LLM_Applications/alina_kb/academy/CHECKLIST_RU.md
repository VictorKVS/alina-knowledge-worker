# ALINA — чек-лист перед приёмом информации

- [ ] Для какой задачи и агента нужен материал? Что нового даёт?
- [ ] Разрешено ли получение, хранение и использование для заявленной цели?
- [ ] Проверены ПДн, секреты, риски публикации и внешней передачи?
- [ ] Есть URL/автор/дата/редакция/язык/источник?
- [ ] Есть raw SHA-256 и hash нормализованного текста?
- [ ] Сохранились таблицы, формулы, подписи, нумерация и страницы?
- [ ] Сопоставлены file duplicate, text duplicate, near duplicate, semantic variant?
- [ ] Различены репост и независимое подтверждение OSINT?
- [ ] Различены старая и новая редакции документа?
- [ ] Противоречия не скрыты?
- [ ] Есть ссылки на исходный фрагмент для каждого факта?
- [ ] Назначение разделено: metadata/graph/RAG/training/eval/holdout/public?
- [ ] Не попали ли экзаменационные эталоны в обучение?
- [ ] Есть решение, причина, владелец, время, история версий, evidence?

**UNKNOWN ≠ PASS**. Неполная информация → проверка или карантин.
