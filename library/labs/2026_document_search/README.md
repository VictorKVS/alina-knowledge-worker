# Лабораторная работа № 1 — «Поиск перед генерацией»

**Цель:** освоить проверяемое извлечение сведений. Это не LLM, не векторная БД и не законченный RAG. Данные придуманы специально для обучения.

Запуск: `python -m unittest -v`, затем `python search.py "RAG информация"`.

Метрики: 5 unit-тестов и ручной осмотр результата. На следующем уровне заменить тестовый корпус разрешёнными документами, ввести оценочный датасет и сравнить с embeddings.

**Безопасность:** не считывает файлы пользователя, не выполняет внешние запросы, не исполняет найденный текст.
