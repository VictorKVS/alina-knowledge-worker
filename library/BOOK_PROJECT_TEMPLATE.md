# Шаблон проекта BOOK-PROJECT-001

## 1. Паспорт источника
Название, автор, год, издательство, версия/издание, источник, право на использование, полный/частичный текст, SHA-256, статус проверки.

## 2. Оглавление
Все главы / разделы; mapping к источнику (страницы, адреса).

## 3. Разбор каждого раздела
Цели → определения → тезисы → аргументы автора → формулы → алгоритмы → ограничения → применимость → опровержения/ошибки → ссылки на точные места.

## 4. Реконструкция профессионального мышления
Какие факты эксперт ищет, какие альтернативы сравнивает, когда останавливается, какие измерения требует; **наша реконструкция по доступному тексту, не буквальное чтение мыслей автора**.

## 5. Knowledge Package
Проверяемые записи; source_id, page, source_type, confidence, provenance, applicability, version.

## 6. Learning Package
Задания, эталонные ответы, типовые ошибки, методы проверки и реальные результаты (NOT_RUN до испытания).

## 7. Competency Package
Для каждой роли: trigger, входной контракт, процедура, алгоритмы, инструменты, ограничения, выходной контракт, handoff, escalation, acceptance.

## 8. Experiment / Evidence Package
Benchmark, тестовый протокол, baseline, кандидат, hardware/software версии, raw evidence, reproducibility. No evidence → no qualification.

## 9. Связь с FATHER и OTUS
Карта источников, компетенций, контрактов и зависимостей. Не создавать дублирующие предметные базы вместо общего ALINA Analytical Core.

## 10. Gate
EXTRACTED → REVIEWED → EVALUATED → QUALIFIED; для каждого этапа проверяемые доказательства.
