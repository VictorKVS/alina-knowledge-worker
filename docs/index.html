Пересказ источника

Объём проектирования определяется риском

Фэрбенкс предлагает связывать архитектурные действия с конкретными возможными отказами. Для разных рисков нужны разные методы проверки. Достаточность работы оценивается по снижению неопределённости, а не по количеству подготовленных диаграмм.

01 / PDF 56–57 · стр. 38–39

Объяснимый выбор метода

Зафиксировать риск, выбранный способ работы с ним и основание считать результат достаточным. Единый шаблон диаграмм не заменяет этот выбор.

02 / PDF 58–60 · стр. 40–42

Проверяемый сценарий отказа

Преобразовать общее опасение в ситуацию, для которой можно проверить результат. Отличать инженерные риски от организационных.

03 / PDF 64–65 · стр. 46–47

Модель под конкретный вопрос

Представление системы должно раскрывать нужные свойства. Время анализа соотносят с риском неудачи, сохраняя баланс с реализацией.

Критическая проверка

Одна книга — один источник. Независимого подтверждения пользы для FATHER пока нет.
Альтернатива: для небольшого прототипа может хватить простой очереди и ручного чек-листа.
Нельзя обещать ускорение или рост качества без измерений до и после.
Решение человека: отобрать предложение для эксперимента. Автоматического изменения базы нет.
