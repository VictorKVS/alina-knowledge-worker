# Сценарий видео

1. Откройте https://victorkvs.github.io/alina-knowledge-worker/visual.html
2. Покажите оригинальную страницу и раскройте дополнительный график.
3. Скачайте страницу по ссылке над изображением. Нажмите выбор файла и загрузите скачанный PNG: сайт подтвердит совпадение SHA-256.
4. Покажите текст вопроса. Нажмите «Показать подготовленный разбор» и дождитесь 10 секунд.
5. Покажите элементы схемы, обратную связь, роли агентов и эксперимент для FATHER.
6. Скачайте текстовый отчёт.

Озвучьте: это подготовленный разбор конкретной страницы, не новая генерация. Чужая картинка только отображается, готовый ответ к ней не подставляется. Для полного ДЗ ещё нужен живой мультимодальный анализ.

Источник иллюстраций: George Fairbanks, Just Enough Software Architecture: A Risk-Driven Approach, глава 3. Страница PDF 75 / печатная 57 и рисунок 3.5 со страницы PDF 73 / печатной 55. Публикуются только выбранные иллюстративные фрагменты для запрошенного разбора, не книга и не база знаний.
