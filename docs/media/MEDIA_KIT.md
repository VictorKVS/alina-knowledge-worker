# ALINA Media Kit

## One-line positioning

**ALINA is an evidence-first knowledge-analysis system that turns heterogeneous sources into structured, verifiable expertise.**

## Short positioning

ALINA explores what comes after simple "chat with documents": source classification, domain-specific analysis profiles, typed knowledge, evidence-linked graphs and qualified digital specialists whose LLM can be replaced without losing the specialist itself.

## Core message

```text
Not:
PDF → chunks → RAG → answer

But:
SOURCE
→ CLASSIFY
→ SPECIALIZED ANALYSIS
→ KNOWLEDGE GRAPH
→ EVIDENCE
→ QUALIFIED EXPERT
```

## Public themes for posts

1. Why one RAG pipeline cannot analyze every kind of knowledge.
2. Why a digital specialist must not be equal to one LLM.
3. A0–A5: routing analysis depth instead of sending everything to a large model.
4. Books as knowledge graphs: characters, events, beliefs, motives and causality.
5. Regulations as machine-readable requirements instead of PDF chunks.
6. Security knowledge as a graph of requirements, assets, threats, risks, controls and evidence.
7. How to replace an LLM without destroying the expert built around it.
8. Evidence-first AI: why provenance matters more than model confidence.
9. The Analysis Profile Registry: one engine, many analytical methods.
10. FATHER + ALINA: expert factory and specialist lifecycle.

## Public communication rule

Always separate:

- implemented;
- experimentally demonstrated;
- designed;
- planned.

Do not market a roadmap item as a finished capability.

This distinction is part of ALINA's evidence-first philosophy.
