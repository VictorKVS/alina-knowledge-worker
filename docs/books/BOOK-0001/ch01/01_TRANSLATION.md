# Chapter 1 — Russian Translation Notes

This is a traceable derived translation/summary, not a replacement copy of the book.

## LLM introduction

**Source:** early Chapter 1

Большая языковая модель рассматривается как вероятностная система генерации языка. Глава вводит базовую терминологию, историю развития, сильные стороны и ограничения современных LLM.

## Prompting

**Source:** approx. pp. 50–60

Промпт — управляемый вход модели. Глава разбирает zero-shot, few-shot, chain-of-thought, prompt chaining и adversarial prompting.

Ключевой инженерный момент: промпт чувствителен к смене модели. Автор называет деградацию поведения одного и того же промпта при смене/обновлении модели **prompt drift** и рекомендует версионировать промпты.

## API access

**Source:** approx. pp. 61–64

LLM может вызываться программно через API. Параметры генерации и формат запроса являются частью поведения приложения и должны рассматриваться как управляемая конфигурация.

## Chat with PDF prototype

**Source:** approx. pp. 70–77

Прототип разбивает документ на фрагменты, создаёт эмбеддинги, сохраняет их в векторном хранилище, преобразует пользовательский запрос в embedding, извлекает похожие фрагменты и передаёт найденный контекст LLM для генерации ответа. История диалога сохраняется отдельно.

## Prototype → Production

**Source:** approx. pp. 78–81

Рабочий прототип ещё не является production-системой. Для серьёзного применения нужны требования по точности и надёжности, обоснованный выбор модели, evaluation, возможная адаптация/fine-tuning, работа с hallucinations и reasoning failures, оптимизация latency/cost, инструменты/агенты и более зрелый RAG.
