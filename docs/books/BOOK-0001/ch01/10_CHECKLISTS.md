# Chapter 1 — Checklists

## Prompt checklist

- [ ] task explicit
- [ ] output contract explicit
- [ ] prompt versioned
- [ ] target model/version recorded
- [ ] regression examples exist
- [ ] cost impact measured for verbose reasoning prompts

- [ ] parser

## Production readiness checklist

- [ ] accuracy target
- [ ] reliability target
- [ ] model-selection evidence
- [ ] evaluation metrics
- [ ] benchmark data
- [ ] latency budget
- [ ] cost budget
- [ ] hallucination/reasoning failure analysis
- [ ] tool permissions where applicable
- [ ] security controls outside model
- [ ] observability
- [ ] evidence retained
