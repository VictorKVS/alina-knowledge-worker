# Chapter 1 — Glossary

| Original term | Canonical RU | Meaning in this chapter |
|---|---|---|
| Large Language Model (LLM) | большая языковая модель | probabilistic language model used for generation and language tasks |
| prompt | промпт / инструкция | model input containing instruction and optionally data/examples |
| context | контекст | text available to the model for prediction |
| zero-shot prompting | zero-shot промптинг | task instruction without examples |
| few-shot prompting | few-shot промптинг | task instruction with demonstrations/examples in context |
| chain-of-thought | цепочка рассуждений | eliciting intermediate reasoning steps for some reasoning tasks |
| prompt chaining | цепочка промптов | decomposing a task into sequential prompts |
| prompt drift | дрейф промпта | behavior degradation when model/version changes |
| adversarial prompting | состязательный/атакующий промптинг | crafted prompts intended to bypass expected behavior/alignment |
| embedding | эмбеддинг | vector representation used for similarity/retrieval |
| retrieval | извлечение | finding potentially relevant external context |
| RAG | генерация с дополнением извлечёнными данными | retrieval-backed generation |
| hallucination | галлюцинация модели | generated content not sufficiently grounded/correct |
| latency | задержка | response waiting time |
| evaluation | оценивание | systematic measurement against tasks/metrics |
