# Chapter 1 — Application Areas

## Prompting

Use for:
- classification;
- extraction;
- controlled generation;
- transformation;
- multi-step workflows.

Avoid treating prompt-only success as sufficient for production without regression tests.

## RAG / document QA

Use when the application must answer from external documents rather than only model memory.

Potential FATHER products:
- ALINA;
- OSINT;
- CyberED;
- BOOKCRAFT;
- internal knowledge assistants.

## Prompt chaining

Use when a task naturally decomposes into stages such as:
1. extraction;
2. validation/postprocessing;
3. formatting.

## Tools / agents

Use when tasks require:
- calculations;
- database access;
- external APIs;
- environmental actions;
- multi-step autonomous decomposition.

## Production engineering

Use Chapter 1 as the first readiness checklist for any LLM product.
